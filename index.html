2. One-Week Revision Plan (2 hrs/day · 14 hrs total) — Beginner-Friendly

Each day = 2 × 1-hour blocks. Because ML basics are weak, days 1–2 are pure foundations: without them, parallelism & inference lectures will feel like jargon. Use a notebook to redo every formula by hand. Use online resources (3Blue1Brown for backprop, Karpathy's "Let's build GPT" for transformers) if a slide is unclear.

Day Block Focus What to do
Day 1
FOUNDATIONS I		 A · 1 hr ML Preliminaries (L2) Learn the vocabulary first: features/labels, train/val/test split, supervised vs unsupervised, overfitting/underfitting, bias–variance. Loss functions: MSE (regression), cross-entropy (classification) — write both formulas. Logistic regression = linear layer + sigmoid + cross-entropy. Goal: be able to say what "training a model" mechanically means.
B · 1 hr SGD & Optimisers (L3) Gradient descent intuition (downhill on loss surface). Difference between full-batch GD, mini-batch SGD, and online SGD — why mini-batch is used in practice. Write the update rules for: SGD, SGD+momentum, Adam/AdamW. By hand, do one step of SGD on f(w) = (w−3)² from w=0, lr=0.1.
Day 2
FOUNDATIONS II		 A · 1 hr Backprop & Autodiff (L4) Computation graph idea (nodes = ops, edges = tensors). Forward-mode vs reverse-mode autodiff — why reverse-mode is used for deep nets (one backward pass gives all gradients). Manually backprop a 2-layer MLP: y = W₂ · ReLU(W₁x) with MSE loss. Then read about gradient checkpointing (trade compute for memory) — this reappears in parallelism.
B · 1 hr Transformer Architecture (L5) THE most important lecture — every later topic builds on it. Draw the decoder-only block from scratch: Input → LN → MHA → +residual → LN → FFN → +residual. For MHA, write the Q/K/V shapes: input [B, N, d], heads h, head dim d_h = d/h. Softmax(QKᵀ/√d_h)V. Tokenisation (BPE) at a high level; RoPE positional encoding intuition. Watch a short Karpathy video if confused.
Day 3
PRETRAIN + GPU		 A · 1 hr Pretraining & GPU Perf (L6–7) CLM objective (predict next token); dataset pipeline at a high level; Chinchilla scaling law (tokens ≈ 20 × params). GPU memory hierarchy: HBM (big, slow) vs SRAM (small, fast). Roofline model: compute-bound vs memory-bound; arithmetic intensity = FLOPs / bytes. Why this matters: decoding is memory-bound — that drives ALL inference optimisations.
B · 1 hr Collective Communication (L8) Why collectives exist: gradients/activations must move between GPUs. Learn 4 primitives with diagrams: Broadcast, AllReduce, AllGather, ReduceScatter. Ring AllReduce cost ≈ 2(N−1)/N · M / BW. NVLink > PCIe > InfiniBand (bandwidth order). Don't memorise numbers — understand when each collective is triggered.
Day 4
PARALLELISM		 A · 1 hr Data & Pipeline Parallel (L9) Data parallel: each GPU has full model, processes different batch, gradients AllReduced. ZeRO-1/2/3 progressively shards optimiser states / gradients / parameters — memorise the savings table. Pipeline parallel: layers split across GPUs. GPipe (sync, big bubble) vs 1F1B (interleaved, smaller bubble). Bubble fraction = (p−1)/(m+p−1). Draw timing diagrams.
B · 1 hr Tensor / Sequence / MoE Parallel (L10–11) Tensor parallel (Megatron): split a linear layer's weight matrix. Column-parallel then row-parallel in MLP block — mark where AllReduce happens (2 per transformer block: MLP and attention). Sequence parallel = split along sequence dim to save activation memory. MoE: gating network → top-k experts → All-to-All comms. Capacity factor & load-balancing loss. Combine all → 3D parallelism.
Day 5
INFERENCE (highest weight)		 A · 1 hr Generative Inference Basics + Algorithm Opts (L13–14) Prefill (compute-bound, parallel over tokens) vs decode (memory-bound, one token at a time). KV-cache: derive size = 2 · n_layers · n_heads · d_head · seq_len · batch · bytes. It dominates memory at long context. Sampling: greedy, top-k, top-p, temperature. FlashAttention: tile Q/K/V, online softmax → avoid materialising the N×N matrix. Speculative decoding: small draft model proposes, big model verifies.
B · 1 hr Inference System Opts + Scaling (L15, L17) PagedAttention / vLLM: KV cache stored in fixed-size pages (like OS virtual memory) → no fragmentation. Continuous batching: requests join/leave the batch mid-flight → much higher throughput than static batching. Quantisation: FP16 → INT8/FP8/INT4 (GPTQ, AWQ, SmoothQuant). Inference-time scaling: Best-of-N, self-consistency, MCTS, o1-style chain-of-thought with process reward models.
Day 6
POST-TRAIN + APPLICATIONS		 A · 1 hr RAG, Agents, Prompting (L16, L18–19) Prompting: zero-shot, few-shot, CoT ("Let's think step by step"), self-consistency, ReAct. RAG pipeline (memorise the 5 steps): chunk → embed → index (vector DB) → retrieve (dense/sparse/hybrid + rerank) → augment prompt → generate. Agents: plan → act (tool/function call) → observe → repeat. Types of memory (short-term context, long-term vector store).
B · 1 hr PEFT, RLHF, Evaluation (L20–22) LoRA: freeze W, train low-rank ΔW = BA where B ∈ ℝd×r, A ∈ ℝr×d, r ≪ d. Params drop from d² to 2dr. QLoRA = LoRA on a 4-bit quantised base model. RLHF: SFT → reward model → PPO. DPO = skip the RM, optimise directly on preference pairs. GRPO = group-relative variant used in DeepSeek. Benchmarks: MMLU, GSM8K, HumanEval (pass@k), MT-Bench, Chatbot Arena (Elo), LLM-as-judge — know what each measures and its weakness.
Day 7
MOCK + PATCH		 A · 1 hr Full timed mock exam Slides closed. Work through the L12 midterm review + L24 final review questions under exam conditions. Mark every question where you hesitated more than 30 seconds — these are your weak spots.
B · 1 hr Weak-spot patch + 1-page cheat sheet Re-derive ONLY your 3–5 weakest topics out loud. Then build a single A4 formula sheet: KV-cache size · AllReduce ring cost · ZeRO memory · pipeline bubble · LoRA param count · Chinchilla 20× ratio · roofline arithmetic intensity · attention softmax(QKᵀ/√d)V. Sleep early.

Beginner rules: (1) Never memorise a formula you cannot interpret — always say "this term represents X" out loud. (2) If a lecture slide is opaque, spend 5–10 min on an external explainer (3Blue1Brown, Karpathy, Lilian Weng's blog) before returning. (3) Active recall > re-reading. (4) Don't skip Days 1–2 to save time — without them, Days 3–6 will not stick.
