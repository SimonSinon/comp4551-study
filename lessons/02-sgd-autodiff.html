Stochastic Gradient Descent & Automatic Differentiation

Prerequisites

  • Derivatives and chain rule.
By the end you can:
  • Write the update rule for SGD, SGD+momentum, and Adam.
  • Explain why mini-batch SGD is the standard, not full-batch GD.
  • Build a computation graph and run reverse-mode autodiff by hand for a small expression.
  • Describe gradient checkpointing and when to use it.

1. Concepts

Gradient descent (GD)

Intuition: stand on a hill (loss surface), look at the slope (gradient), take a step downhill. Repeat.

\[\theta \leftarrow \theta-\eta\nabla_{\theta}L(\theta)\]

\(\eta\) is the learning rate. Too big → overshoot/diverge; too small → glacial.

SGD vs mini-batch vs full-batch

  • Full-batch GD: use ALL N training examples per step. Stable but slow and memory-hungry.
  • SGD (true): 1 example per step. Noisy but fast updates.
  • Mini-batch SGD: batch of B examples (e.g., B=32..2048). The standard. Balances GPU parallelism with noise that helps escape sharp minima.

Momentum & Adam

Plain SGD can zig-zag in narrow valleys. Momentum accumulates a velocity vector:

\[\begin{aligned}v&\leftarrow \beta v+\nabla L,\\ \theta&\leftarrow \theta-\eta v,\qquad \beta\approx0.9\end{aligned}\]

Adam = momentum + per-parameter adaptive learning rate using a running estimate of the gradient's squared magnitude. AdamW decouples weight decay from the adaptive update — used in virtually all modern LLM training.

Automatic differentiation (autodiff)

We don't write derivatives by hand for million-parameter networks. Autodiff records every elementary op (the computation graph) and applies the chain rule mechanically.

  • Forward-mode: propagate derivatives alongside values. Cost \(\approx n_{\mathrm{inputs}}\times\) forward. Good when inputs \(\ll\) outputs.
  • Reverse-mode (backprop): one forward pass to cache activations, then one backward pass computes ALL gradients in O(1× forward). Used everywhere in deep learning because n_params ≫ n_outputs (loss is scalar).
Real-world: PyTorch's loss.backward() = reverse-mode autodiff over the dynamically built graph. JAX's grad() is the same idea, statically traced.

Gradient checkpointing

Backprop needs cached activations from the forward pass → memory-heavy. Checkpointing stores only a subset (e.g., one per layer block) and recomputes the missing activations during backward. Trades ~30% extra compute for large memory savings. Critical when training large transformers.

2. Socratic check

If the loss explodes after a few steps, what's the most likely cause and the first fix?

Learning rate too high. Reduce \(\eta\) (often by \(10\times\)) or add gradient clipping.

Why is reverse-mode autodiff preferred for neural nets but forward-mode is fine for some scientific code?

Reverse-mode cost \(\approx1\) forward pass regardless of #parameters, but \(\approx\)#outputs forward passes. NNs have 1 scalar output (loss) and millions of inputs (params) → reverse wins massively. Scientific code with few inputs and many outputs is the opposite case.

Gradient checkpointing slows training. Why use it?

Because memory is often the binding constraint for large models — without it, the model wouldn't fit on the GPU at all. ~30% extra time is acceptable to enable training.

3. Exercises

Q1. One step of SGD on \(f(w)=(w-3)^2\) from \(w=0\), learning rate \(\eta=0.1\). New \(w\) =

\(f'(w)=2(w-3)\). Evaluate at \(w=0\), then \(w\leftarrow w-\eta f'(w)\).
\(f'(0)=2(0-3)=-6\). \(w\leftarrow0-0.1(-6)=\) 0.6.

Q2. A batch of 1024 examples is split across 8 GPUs (data parallel). Each GPU computes the gradient on its examples, then all gradients are averaged.

1024 / 8 = ?
128 examples/GPU. This is called the "per-device batch size".

Q3. The optimiser used by almost all modern LLM training is .

It decouples weight decay from Adam.
AdamW — Adam with decoupled weight decay (Loshchilov & Hutter, 2019).

Q4. Reverse-mode autodiff for the expression \(L=(xw-y)^2\) at \(x=2,w=3,y=4\). The gradient \(\partial L/\partial w\) =

Let \(u=xw-y\). Then \(L=u^2\). \(\partial L/\partial w=2ux\).
\(u=2\cdot3-4=2\). \(\partial L/\partial w=2\cdot2\cdot2=\) 8.

Q5. Storing all activations for a 100-layer transformer runs out of GPU memory. The technique that recomputes activations during the backward pass to save memory is called gradient .

Sometimes called "activation recomputation".
Gradient checkpointing (a.k.a. activation recomputation). Trades ~30% extra compute for large memory savings.

Q6. The momentum coefficient \(\beta\) in SGD+momentum is typically .

Very common default. Less than 1, more than 0.5.
0.9 is the standard default. Higher (0.99) gives more smoothing but slower adaptation.

Think about how each mode "fans out": forward sweeps one input variable through the graph; reverse sweeps one output backward.
Forward ∝ #inputs, reverse ∝ #outputs. NN loss is scalar (1 output) → reverse-mode is ideal.

Key Takeaways

  • Mini-batch SGD is the default; AdamW dominates LLM training.
  • Update: \(\theta\leftarrow\theta-\eta\nabla L\). Learning rate is the most critical hyperparameter.
  • Reverse-mode autodiff = backprop = one backward pass for all params.
  • Gradient checkpointing trades compute for memory, enabling huge models.
