Lesson 9 · Medium priority

Prompt Engineering

Prerequisites
  • Lesson 3 (LLMs predict next token).
  • Lesson 7 (sampling).
By the end you can:
  • Distinguish zero-shot, few-shot, chain-of-thought, and self-consistency.
  • Apply ReAct to combine reasoning and tool calls.
  • Recognise common prompt failure modes.

1. Concepts

In-context learning (ICL)

LLMs can learn tasks from the prompt, without weight updates. The prompt format itself is the program.

Zero-shot vs few-shot

  • Zero-shot: instruction only. "Translate to French: 'Hello world'"
  • Few-shot: include 2–8 worked examples before the actual query. Often dramatically better, especially for structured outputs.

Chain-of-Thought (CoT)

Append "Let's think step by step" or include example solutions that show intermediate reasoning. Forces the model to expand its computation across more tokens before answering. Huge gains on math/logic tasks.

Self-consistency

Sample multiple CoT completions with temperature > 0, then majority-vote the final answer. Trades compute for accuracy. Works because the right answer often appears via multiple reasoning paths but wrong answers are uncorrelated.

ReAct: Reason + Act

Interleave reasoning ("Thought") and tool calls ("Action") in a loop: Thought → Action → Observation → Thought → …. Backbone of modern agents (Lesson 11).

Common failure modes

  • Prompt injection: attacker text in retrieved content overrides system prompt.
  • Hallucination: confident but false output. Mitigate with retrieval + chain-of-thought + verification.
  • Format drift: model wanders from required JSON. Mitigate with constrained decoding / explicit schemas.
Real-world: GSM8K accuracy jumps from ~18% (zero-shot) to ~57% (8-shot CoT) on PaLM, and self-consistency adds another ~10%.

2. Socratic check

Why does CoT help on arithmetic but rarely on simple sentiment classification?

Arithmetic needs multi-step reasoning that benefits from token-by-token expansion. Sentiment is a one-shot judgement — extra reasoning adds noise rather than insight.

How does self-consistency differ from temperature 0 + CoT?

Self-consistency uses T > 0 to sample diverse reasoning paths, then majority-votes. T=0 gives a single deterministic chain — if it's wrong, you have nothing to fall back on.

Why is ReAct a "loop" rather than a single prompt?

Because actions return observations that change what should happen next. The model must read each observation and decide the next thought/action. This is the agent core.

3. Exercises

Q1. Showing the model 3 worked examples in the prompt is prompting.

Hint: not zero-shot.
Few-shot. n-shot more generally.

Q2. The prompting trick "Let's think step by step" is called prompting.

3-letter acronym.
Chain-of-thought (CoT).

Q3. Sampling 20 reasoning chains then majority-voting the answer is .

Vote = consensus = consistent.
Self-consistency. Compute-for-accuracy trade.

Q4. Interleaving Thought → Action → Observation is the pattern.

"Reasoning + Acting".
ReAct (Yao et al., 2022).

Q5. An attack where untrusted retrieved text overrides the system prompt is called prompt .

Analogous to SQL injection.
Prompt injection. The model can't distinguish trusted vs untrusted text.

Q6. Confidently producing false information is called .

Borrowed from psychiatry.
Hallucination. RAG (Lesson 10) is the most common mitigation.

Key Takeaways

  • Zero-shot → few-shot → CoT → self-consistency → ReAct (each adds capability or compute).
  • CoT helps multi-step reasoning; not all tasks benefit.
  • Self-consistency = sample + vote; reliable accuracy lift.
  • Watch for prompt injection, hallucination, format drift.
