Transformer Architecture & LLM Pretraining

Prerequisites
  • Lessons 1–2 (loss, backprop, parameters).
  • Matrix multiplication and softmax.
By the end you can:
  • Draw a decoder-only transformer block from memory with correct tensor shapes.
  • Explain multi-head self-attention and write its formula.
  • Describe BPE tokenisation and the causal LM (CLM) objective.
  • Apply the Chinchilla scaling law to a compute budget.

1. Concepts

Tokenisation (BPE)

LLMs read integer token IDs, not raw text. Byte-Pair Encoding starts from bytes and iteratively merges the most frequent pair into a new token. Result: common words = 1 token, rare words = several sub-word pieces. Vocabulary size is usually 32k–128k.

Embeddings + positional encoding

Each token ID is mapped to a vector of dimension d (e.g., 4096) via an embedding table. Self-attention is permutation-invariant, so we inject position. Modern LLMs use RoPE (rotary position embeddings) — rotate Q and K vectors by an angle dependent on position, encoding relative position naturally.

Self-attention (the heart of transformers)

For each token, ask "which other tokens are relevant?" by computing similarities, then take a weighted sum of their values.

Attention(Q, K, V) = softmax(Q Kᵀ / √d_k) · V

Shapes for a batch of B sequences of length N, embedding dim d, h heads, head dim d_h = d/h:

  • Input: X ∈ ℝ^{B×N×d}
  • Q, K, V each: ℝ^{B×h×N×d_h} (after splitting heads)
  • Attention matrix QKᵀ/√d_h: ℝ^{B×h×N×N} ← this is the O(N²) cost
  • Output: concat heads back to ℝ^{B×N×d}

In causal (decoder) attention, a mask zeroes positions where j > i so a token can't see the future.

The transformer block

Modern (LLaMA-style) decoder block, with pre-LayerNorm and residuals:

x ← x + MHA(LN(x)) x ← x + FFN(LN(x)) FFN(x) = W₂ · SiLU(W₁ x) (often gated: SwiGLU)

The FFN typically expands to 4×d (or 8/3·d for gated), then projects back. Stack N such blocks → final LayerNorm → linear "unembedding" → softmax over vocabulary.

Causal LM pretraining objective

Given a sequence of tokens, predict the next token at every position. Loss = average cross-entropy over all positions. This is self-supervised — every token is both an input and a label.

Chinchilla scaling law

For a fixed compute budget C (in FLOPs), the loss-optimal allocation between model parameters N and training tokens D satisfies D ≈ 20 × N. A 70B model wants ~1.4T tokens, not 300B.

Approximate training FLOPs: C ≈ 6 · N · D (factor 6 = forward + backward + optimizer).

Real-world: GPT-3 was 175B params on ~300B tokens (under-trained by Chinchilla rules). LLaMA-2 70B trained on 2T tokens, demonstrating Chinchilla-style allocation pays off.

2. Socratic check

Why divide by √d_k inside the softmax?

Without it, the dot products grow with d_k, pushing softmax into saturation (tiny gradients). Dividing by √d_k keeps variances ≈ 1, so the softmax stays in a useful range.

Why multiple attention heads instead of one big head?

Different heads can learn different relations (syntax, coreference, position) in parallel. Splitting into heads is essentially free since the total dimension is unchanged.

Why are residual connections (the "+x") essential?

They give gradients a direct highway back through the network, mitigating vanishing gradients and enabling very deep stacks. They also make each block learn a residual update rather than a full transform.

Suppose you have compute for a 30B model. By Chinchilla, how many tokens should you train on?

~600B tokens (20 × 30B).

Key Takeaways

  • Self-attention: softmax(QKᵀ/√d_k)V — O(N²) in sequence length.
  • Decoder block = LN → MHA → +residual → LN → FFN → +residual.
  • Pretrain with next-token CE loss on internet-scale text.
  • Chinchilla: tokens ≈ 20 × params; total compute ≈ 6ND.
  • RoPE is today's standard positional scheme.
